================================================================================
KEY CONCEPTS DOCUMENTED
================================================================================

✓ 3D Tensor Architecture
  - Why: Enables simultaneous training of all N²_D combinations
  - Structure: (N²_D, m, c) where N_D=datasets, m=records, c=features
  - Zero-padding: Required to create uniform tensor dimensions
  - Speedup: O(N²_D) sequential → O(1) parallel

✓ Scalability Notation
  - N_D = number of datasets (17 in this experiment)
  - N²_D = number of combinations (289 in this experiment)
  - m = records per dataset (2000 in this experiment)
  - c = max feature dimension (3072 in this experiment)

✓ Memory Scaling
  - Memory ≈ O(N²_D · m · c)
  - Example: N_D=17 → 6.6GB, N_D=30 → 20GB

✓ Vectorization
  - All N²_D ANNs train simultaneously
  - 100× speedup in practice (N_D=17)
  - Makes ablation study computationally feasible

QUICK START
================================================================================

1. Install dependencies:
   pip install torch numpy pandas scikit-learn scipy matplotlib torchmetrics pillow

2. Download datasets (see DATASETS.md for links)
   Place in datasets/ directory

3. Run SDTI Pipeline.ipynb
   - Start with small test: m=500, epochs=11, sdti_epochs=15
   - Expected F1 > 0.90 in ~45 seconds

4. Analyze results:
   - Results Analysis.ipynb for ablation study
   - CostDataAnalysis.ipynb for manifold analysis
